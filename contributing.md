## 🎧 About

**Windows 10 Activator Net** is a lightweight, open-source utility designed to activate Windows 10 using the KMS (Key Management Service) protocol. It provides a clean, user-friendly interface and fully transparent code that can be audited by anyone.

Built for system administrators, IT professionals, and power users who need a **reliable activation tool** for testing, enterprise deployment, or personal use. The application automatically detects your Windows 10 edition, installs the appropriate generic key, and activates it in seconds.

Everything runs locally on your machine. No telemetry, no hidden processes, and no bundled adware. The tool supports all Windows 10 editions (Home, Pro, Enterprise, Education) with automatic license renewal every 180 days.

## 📂 Architecture

```bash
windows-10-activator/
│
├── 📱  src/                  → Frontend (C# WinForms / WPF)
│   ├── components/          → MainWindow, Settings, Logs
│   ├── pages/               → Activate, Info, Advanced
│   └── utils/               → SystemInfo, KMSClient
│
├── 🦀  core/                 → Backend (C++ / C#)
│   ├── kms/                 → KMS server communication
│   ├── licensing/           → Key generation & validation
│   └── os/                  → Windows API wrappers
│
├── 🧪  tests/                → Unit + integration tests
├── 📦  assets/               → Icons, logos, installers
├── ⚙️  .github/workflows/    → CI/CD (build, test, release)
└── 📖  docs/                 → Wiki, API reference, guides
```
